# 坦克大战（Tank Battle）

一个使用原生 **HTML + CSS + JavaScript** 编写的经典坦克大战网页游戏，单文件 `index.html` 即可运行，无需任何依赖或构建步骤。

## 在线试玩

> 部署到 GitHub Pages 后，可访问：
> `https://<你的用户名>.github.io/tank-battle/`

## 本地运行

直接用浏览器打开 `index.html` 即可，或者：

```bash
# 使用 Python 启动本地服务器
python -m http.server 8000
# 然后访问 http://localhost:8000
```

## 玩法说明

- **目标**：保护底部基地（★），消灭每关的 20 辆敌方坦克。
- **移动**：方向键 或 `W` `A` `S` `D`
- **射击**：空格 或 `J`
- **暂停**：`P` 或 `Esc`
- 手机 / 平板设备上会显示屏幕触控方向键与开火按钮。

## 游戏元素

| 元素 | 说明 |
|------|------|
| 🧱 砖墙 | 可被子弹摧毁 |
| 🔩 钢墙 | 无法被摧毁 |
| 🌲 树林 | 坦克可穿过，且会遮挡坦克与子弹 |
| ⭐ 基地 | 一旦被摧毁则游戏结束 |

## 敌方坦克类型

| 类型 | 特点 | 分值 |
|------|------|------|
| 普通坦克 | 基本单位 | 100 |
| 快速坦克 | 移动更快 | 200 |
| 装甲坦克 | 需击中两次 | 400 |
| 闪光坦克 | 击毁后掉落道具 | 300 |

## 道具

- ⭐ 火力提升：子弹更快、可同时发射更多子弹
- 🛡 护盾：一段时间内无敌
- 命：生命 +1
- 炸：消灭屏幕上所有敌人

## 技术说明

- 纯 Canvas 渲染，`requestAnimationFrame` 游戏循环，基于 `dt` 的帧率无关运动。
- 最高分保存在浏览器 `localStorage` 中。
- 使用 Web Audio API 生成音效。
